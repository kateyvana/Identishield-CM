# ADR-025 — Aucun runtime applicatif installé directement dans la VM ; tout vit dans les images Docker

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Reproductibilité sans divergence de versions.

## Décision
Aucun runtime applicatif installé directement dans la VM ; tout vit dans les images Docker.

## Alternatives rejetées
JDK/Python/Node installés dans la VM.

## Conséquences
La VM est un hôte de conteneurs.
