# ADR-003 — Stack : Java 21/Spring Boot (cœur, PDP), Python (simulateur, évaluation, outils), Kotlin Android natif, Next.js, PostgreSQL, Docker Compose, GitHub Actions

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Compétences du candidat, crédibilité bancaire, Keystore matériel.

## Décision
Stack : Java 21/Spring Boot (cœur, PDP), Python (simulateur, évaluation, outils), Kotlin Android natif, Next.js, PostgreSQL, Docker Compose, GitHub Actions.

## Alternatives rejetées
Flutter/React Native : masquent le Keystore. Node pour le PDP : moins crédible en contexte bancaire. MongoDB : sans garanties transactionnelles utiles.

## Conséquences
Écart de méthode assumé : décision antérieure aux exigences ; figure en contrainte CT-01, jamais en exigence.
