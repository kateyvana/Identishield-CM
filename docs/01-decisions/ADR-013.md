# ADR-013 — Premier enrôlement refusé si changement d'IMSI < CAR_IMSI ; sinon PROBATION CAR_ENROL

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Défaut D-02 : sans cette règle, l'attaquant devient le premier dispositif de confiance (AC-13).

## Décision
Premier enrôlement refusé si changement d'IMSI < CAR_IMSI ; sinon PROBATION CAR_ENROL.

## Alternatives rejetées
Accepter avec probation seule : l'attaquant est légitimé.

## Conséquences
ES-17, UC-01 détaillé, T-AC-13.
