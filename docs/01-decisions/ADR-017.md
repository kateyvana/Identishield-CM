# ADR-017 — Mode d'injection du simulateur (lot vs appel HTTP par transaction)

**Statut :** PROVISOIRE
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
RA-06 : 500 000 appels HTTP probablement incompatibles avec SQ-21.

## Décision
Mode d'injection du simulateur (lot vs appel HTTP par transaction).

## Alternatives rejetées
Appel HTTP par transaction.

## Conséquences
Dépend de SPIKE-5.
