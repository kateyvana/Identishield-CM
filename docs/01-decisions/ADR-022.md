# ADR-022 — Machine virtuelle Ubuntu Server 24.04 sous VirtualBox comme unique environnement d'exécution ; démonstration locale

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Reproductibilité, isolation, fiabilité le jour de la soutenance.

## Décision
Machine virtuelle Ubuntu Server 24.04 sous VirtualBox comme unique environnement d'exécution ; démonstration locale.

## Alternatives rejetées
Docker sur l'hôte ; serveur distant ; cloud ; services natifs sans Docker.

## Conséquences
ISC-DEPLOY ; interface en pont pour les téléphones ; UTC obligatoire.
