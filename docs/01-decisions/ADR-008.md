# ADR-008 — Agent opérateur complice inclus dans le modèle de menace (T-02)

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Sources MINPOSTEL, Financial Afrik, TechTrends : reprogrammation faillible, insiders avérés.

## Décision
Agent opérateur complice inclus dans le modèle de menace (T-02).

## Alternatives rejetées
L'exclure décrirait un contexte qui n'existe pas.

## Conséquences
La probation s'applique indifféremment au motif (ADR-011).
