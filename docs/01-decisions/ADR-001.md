# ADR-001 — PDP séparé appelé par le cœur via /evaluate ; décision graduée ALLOW / STEP_UP / FREEZE

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Le cœur opérateur simulé doit être protégé sans réécriture ; le jury doit voir le contrat.

## Décision
PDP séparé appelé par le cœur via /evaluate ; décision graduée ALLOW / STEP_UP / FREEZE.

## Alternatives rejetées
Bibliothèque embarquée dans le cœur : ne démontre pas le découplage, rend le contrat invisible. Post-traitement asynchrone : ne peut pas empêcher une transaction.

## Conséquences
Un service distinct, un contrat OpenAPI, un appel synchrone avant commit, une politique fail-closed (ADR-007).
