# ADR-019 — Abstraction temporelle Clock injectée, SystemClock / VirtualClock

**Statut :** PROVISOIRE
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
SQ-20, SQ-21, C-08.

## Décision
Abstraction temporelle Clock injectée, SystemClock / VirtualClock.

## Alternatives rejetées
Horloge statique : règles temporelles intestables.

## Conséquences
Dépend de SPIKE-2.
