# ADR-004 — Poste attaquant : CLI + chronologie d'attaque dans la console (option C)

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Le jury doit comprendre ; le réalisme impose un terminal.

## Décision
Poste attaquant : CLI + chronologie d'attaque dans la console (option C).

## Alternatives rejetées
Interface web attaquant seule : artificielle. CLI seul : illisible pour un jury non technique.

## Conséquences
Outil attaquant Python publiant chaque étape vers la console.
