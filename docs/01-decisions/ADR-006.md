# ADR-006 — Exécution du code par agent de codage sous spécification et revue du candidat ; déclaration dans le mémoire

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Un candidat, sept mois, périmètre large.

## Décision
Exécution du code par agent de codage sous spécification et revue du candidat ; déclaration dans le mémoire.

## Alternatives rejetées
Implémentation manuelle intégrale : incompatible avec le périmètre.

## Conséquences
CLAUDE.md, protocole de délégation ISC-DEV §5, revue ligne à ligne du code crypto (ENF-08c), ENF-15.
