# ADR-009 — Journal d'audit par chaînage d'empreintes SHA-256, écriture seule, ancrage périodique signé

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Preuve a posteriori nécessaire ; insider SOC dans le modèle (T-04).

## Décision
Journal d'audit par chaînage d'empreintes SHA-256, écriture seule, ancrage périodique signé.

## Alternatives rejetées
Chaîne de blocs : théâtre technique sans gain en mono-organisation. Journal applicatif simple : ne prouve rien.

## Conséquences
Rôle base INSERT seul (ED-06), composant AuditLog unique.
