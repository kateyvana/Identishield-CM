# ADR-007 — Fail-closed au-dessus de CAP_PROB si le PDP est indisponible ; micro-paiements en mode dégradé journalisé

**Statut :** FERME
**Date :** 2026-08-20
**Source :** ISC-SAD §15 / ISC-DEPLOY §9

## Contexte
Une panne du PDP ne doit pas ouvrir une fenêtre d'attaque (AC-12).

## Décision
Fail-closed au-dessus de CAP_PROB si le PDP est indisponible ; micro-paiements en mode dégradé journalisé.

## Alternatives rejetées
Fail-open : fenêtre triviale. Fail-closed total : bloque les micro-paiements sans gain proportionné.

## Conséquences
Coût mesuré par EXP-6 (H5).
